# AGENTS.md

## Overview

Kotlin Spring Boot service (`pgk-proxy`) that integrates a local Matrix Synapse server with a HAPI FHIR server. It serves FHIR-backed user-directory search at the Matrix endpoint `POST /_matrix/client/v3/user_directory/search` (port 8081 backing store). Matrix traffic otherwise goes straight to Synapse (no proxy in the path). This is a PoC for the "PGK" (Health Portal) federation.

## Commands

- Build/test (Java toolchain 21 required): `./gradlew build`
- Run a single test class: `./gradlew test --tests "io.cloudflight.pgk.proxy.search.domain.service.PractitionerConsolidatorTest"`
- Focused unit test of one module's package: `./gradlew test --tests "io.cloudflight.pgk.proxy.search.application.*"`
- Run the app locally: IDE run config `.run/pgk-proxy.run.xml` uses the `local` profile; roughly `./gradlew bootRun --args='--spring.profiles.active=local'`
- Do NOT run `./gradlew build`/`test` or start the app locally unless the user explicitly asks. A Java 21 JDK is not installed in this environment.

## Architecture (Spring Modulith + hexagonal)

- One Gradle module. 60 Kotlin files under `src/main/kotlin/io/cloudflight/pgk/proxy/`.
- Spring Modulith enforces module boundaries at build/test time — `ModularityTests`/`DocumentationTests` (`src/test/kotlin/.../proxy/`) run on every `./gradlew test`. Module = package under the root that is *not* `shared`.
- Per-feature module (`search`, `federation`, `invitation`, `provisioning`) follows hexagonal layout: `adapter/inbound`, `adapter/outbound`, `application`, `domain/{model,service}`, `port`. `infrastructure/*` holds global concerns (FHIR config, routing, audit).
- Ports are exposed with `@NamedInterface("port")` on the interface itself (see `federation/port`, `provisioning/port`) — not via a `ModuleMetadata` class.
- `shared` is an OPEN Modulith module (`SharedModule.kt`) — cross-module shared types (Mxid, TrustLevel, events) MUST live there, not in feature modules, or modularity verification fails.

## Key integration details

- FHIR via HAPI FHIR R4 (`hapi-fhir-structures-r4` 8.10.1). Central `pgk.fhir.base-url`, default `http://localhost:8081/fhir`. Outbound adapters live in `search/adapter/outbound`, each with a `<Entity>SearchMapper`.
- The app does NOT proxy to Synapse. Traefik routes `matrix.traefik.me` straight to Synapse for everything except the single app endpoint (`/_matrix/client/v3/user_directory/search`), which goes to the app.
- IDP provisioning: the Keycloak SPI (event listener `pgk-idp-provisioning`) lives in its own Gradle subproject
  `keycloak-provider` (package `io.cloudflight.pgk.keycloakprovider`), not in the proxy's source tree. The classes are NOT
  Spring beans - they run inside the Keycloak runtime, and Keycloak SPI deps are `compileOnly` so they never land on the
  pgk-proxy classpath. `./gradlew :keycloak-provider:keycloakProviderJar` packages that subproject (plus kotlin-stdlib)
  into `keycloak-provider/build/keycloak` for `/opt/keycloak/providers`. They talk to the `provisioning` module over
  `/internal/idp/**`, authenticated only by HTTP Basic (user `pgk-idp`, password `pgk.idp.webhook-secret`).

## Local environment (docker-compose)

`docker-compose.yml` provisions the whole dependency stack: Matrix Synapse (8008), Element client (8090), a HAPI FHIR server (`pgk-fhir`, 8081→8080) with Postgres, plus init containers that fix Lucene index ownership (uid 65532) and upload SearchParameter JSON files from `config/pgk-fhir/searchparams/` on startup. Use this to get real search results locally; the app alone returns nothing without the FHIR/Synapse stack.

## Gotchas

- Local dev uses the single `local` profile (`application-local.yml`). Traefik routes `matrix.traefik.me` → Synapse directly except for `/_matrix/client/v3/user_directory/search` → the app (HTTP :8080). Keycloak (SSO login) is served directly at `idp.traefik.me`. All local hostnames use `*.traefik.me` (public wildcard DNS → 127.0.0.1) to avoid the `.localhost`-loopback federation bug; each Synapse pins its peer via `extra_hosts` (`partner.traefik.me:host-gateway` / `matrix.traefik.me:host-gateway`).
- `config/synapse/matrix.local.signing.key` is gitignored and generated by the `matrix-init` compose service on first run.
- Kotlin compiler args in `build.gradle.kts`: `-Xjsr305=strict`, `-Xannotation-default-target=param-property` — keep these when editing compiler setup.
- Java toolchain is fixed at 21; the CI `step-test` also constrains Gradle memory (2g heap / 768m metaspace).
